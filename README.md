# PolyclinicQueue — запуск

1. Откройте базу: MySQL Workbench → File → Open SQL Script → `Database/PolyclinicQueue_full.sql` → ⚡ Execute.
   (Скрипт пересоздаёт базу PolyclinicQueue вместе с тестовыми данными.)
2. Откройте `PolyclinicQueue.sln` в Visual Studio 2022 (.NET 8 SDK, нагрузка «ASP.NET и веб-разработка»).
3. В `PolyclinicQueue.API/appsettings.json` замените `pwd=1234` на пароль вашего MySQL.
4. Нажмите F5 → http://localhost:5100 (Swagger: /swagger).

## Тестовые входы
| Логин | Пароль | Роль |
|---|---|---|
| admin | admin123 | Администратор |
| doctor1 | doc123 | Стоматолог (Иванов) |
| doctor4 | doc123 | Стоматолог (Орлова) — видит тех же пациентов, что и doctor1 |
| doctor2 | doc123 | Терапевт |
| doctor3 | doc123 | Кардиолог |
| patient1 / patient2 | pat123 | Пациенты |

## Как работает «картотека по специальности»
Врач видит только тех пациентов (и только те обращения), которые связаны с врачами ЕГО специальности.
Стоматолог — пациентов, лечивших зубы в поликлинике; кардиолог — кардиологических и т.д.
Специальность сравнивается по тексту поля «Специализация», поэтому у врачей одной специальности оно должно быть записано одинаково.

## Заметки
- Регистрация пациента (index.html → «Регистрация») пишет логин/пароль в `Users`, анкету — в `Patients`.
- Администратор добавляет сотрудника в «Врачи → Добавить сотрудника»: личные данные, контакты, работа, логин/пароль → `Users` + `Doctors`.
- Пароли хранятся и сравниваются открытым текстом (как в ваших тестовых данных).
- Нужен интернет в браузере: Font Awesome, Chart.js, jsPDF подключаются с cdnjs.cloudflare.com.
- Если база осталась старой (без новых колонок) — приложение при старте само добавит недостающие колонки.
